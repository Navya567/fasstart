✅ 5. Case Approval Flow
Approve application with AI email generation, notifications, and external system integration
UI
Approve Button
Caseworker decision
→
AI
Bedrock AgentCore
Draft approval email
→
UI
Email Review Modal
Edit & confirm
→
COMPUTE
DecisionLambda
Process approval
⚙️ Backend Process:
1
Caseworker clicks Approve → Frontend calls Bedrock with approval context (case details, applicant info)
2
AI generates approval email with personalized content based on case facts and policy rules
3
Frontend displays editable email draft → Caseworker reviews/edits → Clicks "Confirm & Send"
4
Lambda validates caseworker has permission for this case
5
Update Aurora: SET status='APPROVED', approved_by=user_id, approved_at=NOW()
6
Audit log written to Aurora audit_logs table
7
SES sends approval email to both citizen (applicant) AND assigned manager
8
EventBridge event published: CaseApproved with case_id payload
9
External systems can consume our API via GET /api/cases/{case_id} to retrieve approval status and update their own systems
10
Notification stored in DynamoDB notifications table for manager dashboard

⚙️ 9. Settings & Profile Photo Upload Flow
Update user preferences and upload profile photo
UI
Settings Page
Photo upload input
→
GATEWAY
API Gateway
POST /upload
→
COMPUTE
UploadLambda
Validate & upload
→
STORAGE
S3
user-profiles bucket
⚙️ Backend Process:
1
User uploads photo (JPG/PNG, max 5MB) → Frontend base64 encodes image
2
Lambda validates file type, size, and scans for malware using S3 Object Lambda
3
Image uploaded to S3: s3://user-profiles/{user_id}/profile.jpg
4
Generate CloudFront signed URL for secure photo access with 24hr expiration
5
Update Aurora users table: SET profile_photo_url=cloudfront_url, updated_at=NOW()
6
Lambda returns success response with new photo URL → Frontend updates UI immediately
7
Old photo automatically deleted from S3 using lifecycle policy (if exists)
