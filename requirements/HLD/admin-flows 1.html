👥 3. User Management Flow
Create and manage system users with SSO integration
UI
Admin Panel
User list + Create
→
GATEWAY
API Gateway
/admin/users
→
COMPUTE
UserManagementLambda
RBAC enforced
→
AUTH
Cognito + Aurora
SSO account
⚙️ Create User Process:
1
Lambda Authorizer checks JWT for 'admin' group (403 if unauthorized)
2
Add user to Cognito group via SSO provider: caseworker | manager | admin
3
Insert user record into Aurora users table with role metadata
4
Audit log records user creation action by admin
📋 List Users:
1
Query Aurora: SELECT * FROM users WHERE is_deleted=false ORDER BY created_at DESC
2
Display table with: Name, Email, Role, Status (Active/Inactive), Last Login
3
Basic stats panel: Total Users: {count}, Caseworkers: {cw_count}, Managers: {mgr_count}, Admins: {adm_count}
✏️ Update / Delete / Activate / Deactivate User:
1
Update: PATCH /admin/users/{id} → Update name, email, role in Aurora
2
Delete: DELETE /admin/users/{id} → Soft delete: SET is_deleted=true, deleted_at=NOW()
3
Activate: PUT /admin/users/{id}/activate → SET is_active=true, update Cognito user status
4
Deactivate: PUT /admin/users/{id}/deactivate → SET is_active=false, revoke Cognito sessions
5
All operations logged in Aurora audit_logs table with admin_id and action type
📋 4. Policy Configuration Flow
Upload and manage decision policies (Aurora-only storage)
UI
Policy Upload
JSON/YAML file
→
GATEWAY
API Gateway
/admin/policies
→
COMPUTE
PolicyManagementLambda
Validate schema
→
DATA
Aurora
Versioned storage
⚙️ Upload Policy Process:
1
Lambda validates policy file against JSON schema (decision rules, thresholds, benefit types)
2
Insert policy into Aurora policy_versions table with content and version timestamp
3
Audit log records policy upload with admin_id and policy_name
📋 List / Download / Update / Delete Policies:
1
List: GET /admin/policies → Query Aurora policy_versions, display table with name, version, updated_at
2
Download: GET /admin/policies/{id}/download → Retrieve policy JSON from Aurora, return as downloadable file
3
Update: PUT /admin/policies/{id} → Validate new policy, increment version, INSERT new row in Aurora
4
Delete: DELETE /admin/policies/{id} → Soft delete: SET is_deleted=true WHERE policy_id={id}
5
All operations logged in Aurora audit_logs with full change tracking

⚙️ 6. Settings & Profile Photo Upload Flow
Update user preferences and upload profile photo
UI
Settings Page
Photo upload input
→
GATEWAY
API Gateway
POST /upload
→
COMPUTE
UploadLambda
Validate & upload
→
STORAGE
S3
user-profiles bucket
⚙️ Backend Process:
1
User uploads photo (JPG/PNG, max 5MB) → Frontend base64 encodes image
2
Lambda validates file type, size, and scans for malware using S3 Object Lambda
3
Image uploaded to S3: s3://user-profiles/{user_id}/profile.jpg
4
Generate CloudFront signed URL for secure photo access with 24hr expiration
5
Update Aurora users table: SET profile_photo_url=cloudfront_url, updated_at=NOW()
6
Lambda returns success response with new photo URL → Frontend updates UI immediately
7
Old photo automatically deleted from S3 using lifecycle policy (if exists)
